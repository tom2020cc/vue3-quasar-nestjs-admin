一、平台介绍

快手只支持窄屏（竖屏），用的是「快手开放平台」的「发布视频到快手」能力（scope：user_video_publish）。

快手是国内平台，不需要翻墙；但通常要求企业资质才能申请发布能力。

二、第 1 步：注册开发者账号 & 创建应用

快手开放平台 ↗
  1. 打开 快手开放平台，注册 / 登录开发者账号（通常需企业资质）。
  2. 创建应用，得到两个值：
    • App ID → 对应系统的 appId
    • App Secret → 对应系统的 appSecret

三、第 2 步：申请「发布视频」能力

快手开放平台 ↗打开后选择自己的应用，再按下方步骤操作。
  1. 在应用的「能力 / 权限」中申请 「发布视频到快手」（scope user_video_publish）。
  2. 通过审核后才能正常授权与发布。

四、第 3 步：配置回调地址

快手开放平台 ↗打开后选择自己的应用，再按下方步骤操作。

在应用的「安全设置 / 回调配置」中填写：

http://localhost:5001/platform/kuaishou/oauth/callback

五、第 4 步：填进系统「平台配置」页

打开平台配置 / 账号授权 ↗
  1. 打开系统「平台配置」页，找到「快手」，点「配置」。
  2. 填两项，其它留空：
    • 应用ID ← App ID
    • 应用密钥 client_secret ← App Secret
  3. 点「保存」。

六、第 5 步：点「授权」完成授权

打开平台配置 / 账号授权 ↗
  1. 快手那一行点「授权」，跳转快手授权页，授权 user_video_publish。
  2. 授权成功自动回填 accessToken + refreshToken + openId。

七、成功标志

打开平台配置 / 账号授权 ↗ 打开视频发布 ↗
  • 页面弹出：「快手 授权成功，令牌已保存」
  • 表格里「快手」变成 「已配置凭证」

八、易错点汇总

快手开放平台 ↗ 打开平台配置 / 账号授权 ↗
坑现象 / 原因解决办法
发布是异步的发布后约 1 分钟才生效正常现象，系统会轮询最终状态
接口路径有差异发布接口路径对不上不同应用类型接口略有差异，对照官方文档核对
需要企业资质申请能力被拒换企业主体账号申请
回调失败授权后回不来回调地址与系统一致
