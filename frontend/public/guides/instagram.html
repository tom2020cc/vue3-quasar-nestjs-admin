Instagram 接入教程

专业账号 + 绑定 Facebook Page + 对象存储托管视频，用 Content Publishing API 发布 Reels / 视频

Instagram 发布能力已接入，可直接使用。除 Meta 侧准备外，还需配置对象存储（IG 要求视频先有公网 URL），下方按步骤操作即可。

一、平台介绍

Instagram 走 Content Publishing API 发布，只支持专业账号（Business / Creator），普通个人号无法通过 API 发布。

Instagram 视频必须先托管到对象存储拿「公网 URL」，不能直接上传二进制；Reels 通过 API 发布目前仅支持 Business 账号。

二、第 1 步：注册 Meta 开发者 & 创建 App

  1. 打开 Meta for Developers，用你的 Facebook 账号登录。
  2. 进入「我的应用 → 创建应用」，应用类型选择 Business（商务）。
  3. 创建后记下：
    • 应用编号 App ID → 对应系统 appId
    • 应用密钥 App Secret → 对应系统 appSecret
Facebook 与 Instagram 共用同一个 Meta 应用，已按 Facebook 教程建过 App 可直接复用。

三、第 2 步：申请 Instagram 发布权限

在「应用审核 → 权限和功能」中申请（Development Mode 下默认可直接使用）：

  • instagram_business_basic —— 读取 IG 专业账号信息
  • instagram_business_content_publish —— 发布内容（核心）
旧权限 instagram_basic / instagram_content_publish 已于 2025-01 废弃，务必用上面两个新权限。

四、第 3 步：配置回调地址

在「Instagram → 基本显示 / Facebook Login」的 OAuth 设置中，加入下面的跳转 URI：

http://localhost:5001/platform/instagram/oauth/callback

五、第 4 步：准备账号资产

  1. 把你的 Instagram 账号切换为专业账号（IG 里：设置 → 账号类型和工具 → 切换为专业账号 → 选 Business）。
  2. 把该 IG 账号绑定到你的一个 Facebook Page（在 Meta 业务账户 / 专业账户中心里关联）。

六、第 5 步：配置对象存储（必做）

IG 发布时系统会先把视频上传到对象存储、生成公网 URL 再交给 IG 抓取。任选一个 S3 兼容存储（AWS S3 / 阿里云 OSS / 腾讯云 COS / MinIO 等），编辑 backend/.env 填入：

变量说明示例
STORAGE_ENDPOINT存储端点（含协议）https://oss-cn-hangzhou.aliyuncs.com；MinIO：http://localhost:9000
STORAGE_REGION区域oss-cn-hangzhou 或 us-east-1
STORAGE_BUCKET桶名my-video-bucket
STORAGE_ACCESS_KEYAccessKey云厂商控制台获取
STORAGE_SECRET_KEYSecretKey同上
STORAGE_URL_EXPIRES预签名 URL 有效期（秒）172800（48h）
桶需公网可读，预签名 URL 让 IG 在有效期内抓取视频；填好后重启后端生效。
本地开发可用 Docker 起一个 MinIO 自建；生产建议用云厂商 OSS/COS，避免地址不可达导致 Error 36003。

七、第 6 步：填进系统「平台配置」页

  1. 打开系统「平台配置」页：http://localhost:5173/#/platform-config（登录 admin@qq.com / admin123）。
  2. 找到「Instagram」行，点「配置」，填：
    • 应用ID ← App ID
    • 应用密钥 client_secret ← App Secret
  3. 点「保存」。

八、第 7 步：点「授权」

  1. Instagram 行点「授权」，跳转 Meta 授权页。
  2. 选择你的 IG 专业账号和关联 Page，同意授权。
  3. 授权成功自动跳回，令牌 + igUserId 已自动回填。

九、成功标志

  • 页面弹出「Instagram 授权成功，令牌已保存」
  • 表格里 Instagram 行变成「已配置凭证」
  • 数据库写入了 60 天长期 token + pageId + igUserId
  • 发布时后端日志显示「上传对象存储成功」，IG 返回容器 FINISHED 后发布成功

十、易错点汇总

坑现象 / 原因解决办法
个人号无法发布IG 不是专业账号切换为 Business 专业账号
拿不到 IG 账号IG 未绑定 FB Page在账户中心把 IG 绑定 Page
视频抓取失败（Error 36003）视频 URL 非公网或已过期确保对象存储 URL 公网可达且未过期
发布时提示未配置存储STORAGE_* 未填或填错补齐 backend/.env 的 STORAGE_* 并重启后端
发布被限流超过 25 条/24h控制节奏，批量发布分批
