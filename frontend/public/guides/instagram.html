Instagram 创作者账号接入

Instagram 直接授权 · 不需要绑定 Facebook 公共主页

当前进度：项目已修正直接登录、令牌刷新与发布链接获取；模拟测试通过。尚未完成你的账号授权或真实发布验证。当前视频上传仍需对象存储。

接入条件

使用 Instagram 企业或创作者账号。请选择「Instagram API with Instagram Login」，不要混用 Facebook Login 的应用凭证、权限和令牌。

Meta 官方 Instagram Login 说明本地平台配置

1. 准备开发者应用

在 Meta 应用中添加 Instagram，进入「API setup with Instagram login」。按控制台要求配置应用角色、测试账号与访问权限。自己的测试账号与面向其他用户的应用，所需访问级别可能不同，不应把测试通过当成已完成正式审核。

Meta 应用控制台

2. 授予基本资料和发布权限

本项目请求 instagram_business_basic 和 instagram_business_content_publish。使用目标 Instagram 账号授权，无需绑定 Facebook 公共主页。

3. 登记回调地址

将项目「平台配置」显示的后端地址加上 /platform/instagram/oauth/callback，在 Instagram 登录设置登记，协议、主机、端口及路径须完全一致。如果控制台要求 HTTPS，必须先配置合规且匹配的 HTTPS 回调。当前 localhost HTTP 地址是否可接受，需在实际控制台确认；项目不会自动建立公网隧道。

4. 确认目标创作者账号

确认授权页面的账号身份；授权后项目通过官方接口读取 Instagram 用户 ID 和用户名。当前 Instagram 配置只保存一个授权账号，重新授权会更新这一配置。

5. 填写应用信息

在本地平台配置中编辑 Instagram，填写 Instagram 产品登录设置提供的 Instagram App ID / Instagram App Secret。不要填 Facebook App ID、账号密码或其他平台凭证。密钥只保存在本机私有配置，不放进教程或截图。

6. 点击授权

保存配置后点击 Instagram 行的「授权」，在 Instagram 完成授权后返回项目。账号 ID、长期令牌与过期时间自动保存，不需要填写 refresh_token。有效长期令牌可通过「刷新令牌」更新；令牌失效或权限撤销后应重新授权。

7. 准备视频存储

当前实现通过 S3 兼容对象存储生成视频预签名 URL，供 Instagram 抓取。需要配置 STORAGE_ENDPOINT、STORAGE_REGION、STORAGE_BUCKET、STORAGE_ACCESS_KEY、STORAGE_SECRET_KEY。下载地址必须能被平台访问，签名在抓取期间须有效，不必公开整个桶。尚未实测的本地二进制直传不作为当前可用功能。

8. 核对真实发布结果

账号授权和存储就绪后，选择一条获准测试的视频。项目创建媒体容器、等待处理，再提交发布。只有正式发布响应确认成功才标记完成，并查询官方 permalink；获取链接暂时失败时不伪造视频链接，也不因缺少链接重复上传。

模拟发布、容器创建成功、视频处理完成均不能单独证明公开视频已经发布。最终核对 Instagram 账号中的实际作品。

常见问题

  • client_id 或令牌交换错误：核对 Instagram 产品中的应用 ID / Secret，不能混用 Facebook 凭证。
  • 回调错误：核对完整地址和 HTTPS 要求。
  • 权限不足：核对发布权限、应用角色及控制台访问级别。
  • 视频抓取失败：核对预签名地址、网络可达性、有效期和视频格式。

状态含义

「已配置凭证」表示本地有配置；「授权成功」表示令牌已保存；「发布成功」需要实际发布结果。当前尚待用户提供目标账号与开发者应用信息继续验证。
