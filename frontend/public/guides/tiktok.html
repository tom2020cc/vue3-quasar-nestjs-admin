一、平台介绍

TikTok（抖音海外版）只支持窄屏（竖屏），用的是 TikTok Content Posting API，并且强制使用 PKCE（无需 client_secret 也能安全授权，本系统已自动处理）。

二、第 0 步：翻墙准备

TikTok 是海外平台，浏览器和后端都需要能访问。授权、发布都要后端调 TikTok 接口，如果后端连不上会报 授权失败：fetch failed。

把翻墙软件切到「全局 / TUN 模式」，让所有程序（包括 Node 后端）都走代理，不要用「系统代理 / PAC」模式。

三、第 1 步：注册开发者账号 & 创建应用

  1. 打开 TikTok for Developers，登录（通常需要海外账号）。
  2. 进入 My Apps，创建应用。
  3. 应用创建后，在应用详情页能看到：
    • Client Key → 对应系统的 appId
    • Client Secret → 对应系统的 appSecret

四、第 2 步：添加 Content Posting API 产品

  1. 在应用详情里找到 「Content Posting API」，点 Add product / 添加。
  2. 有些账号需要先完成企业验证或提交审核才能启用。

五、第 3 步：配置回调地址

在应用的 Login Kit / Redirect URI 配置中填写：

http://localhost:5001/platform/tiktok/oauth/callback

六、第 4 步：填进系统「平台配置」页

  1. 打开系统「平台配置」页，找到「TikTok 海外版」，点「配置」。
  2. 填两项，其它留空：
    • 应用ID ← Client Key
    • 应用密钥 client_secret ← Client Secret
  3. 点「保存」。

七、第 5 步：点「授权」完成授权

  1. TikTok 那一行点「授权」，跳转 TikTok 授权页，授权 video.publish。
  2. 系统会自动处理 PKCE（code_challenge / code_verifier），你无需手动操作。
  3. 授权成功自动回填 accessToken + refreshToken + openId。

八、成功标志

  • 页面弹出：「TikTok 海外版 授权成功，令牌已保存」
  • 表格里「TikTok 海外版」变成 「已配置凭证」

九、易错点汇总

坑现象 / 原因解决办法
fetch failed后端连不上 TikTok翻墙切「全局 / TUN 模式」
token 过期发布时提示过期access_token 约 24 小时，先点「刷新令牌」
产品没添加授权时没有发布权限先 Add product：Content Posting API
上传地址失效上传超时上传地址 1 小时有效，及时上传
