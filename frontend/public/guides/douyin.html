一、平台介绍

国产抖音用的是「抖音开放平台」的「代替用户发布内容到抖音」能力，宽屏、窄屏都支持，是四个平台里唯一一个两个尺寸都能发的。

抖音是国内平台，不需要翻墙，整个流程都可以直接访问。

二、第 1 步：注册开发者账号 & 创建应用

抖音开放平台 ↗
  1. 打开 抖音开放平台，注册 / 登录（个人或企业均可，部分能力要求企业资质）。
  2. 进入「控制台 → 移动应用 / 网站应用」，点「创建应用」，填写应用名称、图标、简介。
  3. 应用创建后，在「应用详情 → 凭据」页能看到两个值：
    • Client Key → 对应系统的 appId
    • Client Secret → 对应系统的 appSecret

三、第 2 步：申请「代替用户发布内容」能力

抖音开放平台 ↗打开后选择自己的应用，再按下方步骤操作。
  1. 进入应用的「能力管理」，找到 「代替用户发布内容到抖音」，申请开通。
  2. 相关权限：video.create（发布视频）、video.data（查询视频数据，用于轮询最终状态）。
  3. 部分能力需要提交审核，通过后才能在授权时拿到对应权限。

四、第 3 步：配置回调地址

抖音开放平台 ↗打开后选择自己的应用，再按下方步骤操作。

在应用的「安全设置 / 回调配置」中，填写授权回调域：

http://localhost:5001/platform/douyin_cn/oauth/callback
抖音的「授权回调域」通常只校验域名（localhost:5001），不校验完整路径，登记域名即可。

五、第 4 步：填进系统「平台配置」页

打开平台配置 / 账号授权 ↗
  1. 打开系统「平台配置」页：本地平台配置页面 ↗（登录用 admin@qq.com / admin123）。
  2. 找到「国产抖音」这一行，点「配置」。
  3. 填两项，其它留空：
    • 应用ID（client_key / client_id） ← Client Key
    • 应用密钥 client_secret ← Client Secret
  4. 点「保存」。

六、第 5 步：点「授权」完成授权

打开平台配置 / 账号授权 ↗
  1. 抖音那一行点「授权」，跳转到抖音登录 / 授权页。
  2. 用你的抖音账号扫码 / 登录，同意授权。
  3. 授权成功自动跳回，accessToken 和 openId 已自动回填。

七、成功标志

打开平台配置 / 账号授权 ↗ 打开视频发布 ↗
  • 页面弹出：「国产抖音 授权成功，令牌已保存」
  • 表格里「国产抖音」那一行变成 「已配置凭证」
  • 数据库里 accessToken 和 openId 都已写入

八、易错点汇总

抖音开放平台 ↗ 打开平台配置 / 账号授权 ↗
坑现象 / 原因解决办法
走了模拟发布配置显示"未配置"，发布是假的抖音必须 accessToken + openId 两个都有，缺一个就模拟
授权拿不到权限授权页没有发布权限先去「能力管理」申请并等审核通过
回调域不匹配授权后回调失败回调域填 localhost:5001，与系统一致
token 过期发布时提示过期access_token 约 15 天，用「刷新令牌」按钮或重新授权
