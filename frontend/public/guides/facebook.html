Facebook 接入教程

从申请 Meta App → 拿 App ID / Secret → 授权拿到 Page Token，把视频发到自己的 Facebook Page

Facebook 发布能力已接入，可直接使用。发布前先完成下方 Meta 侧准备（建 App、申请权限、准备 Page），再回到系统「平台配置」页填凭证并授权即可。

一、平台介绍

Facebook 走 Graph API 发布视频到你自己的 Facebook Page（公共主页），横屏、竖屏视频都支持。

发布必须使用 Page Access Token（页面令牌），用户令牌会报 #100 No permission。
Facebook 直接上传视频二进制，不需要对象存储（与 Instagram 不同）。

二、第 1 步：注册 Meta 开发者 & 创建 App

Meta 开发者平台 ↗
  1. 打开 Meta for Developers，用你的 Facebook 账号登录。
  2. 进入「我的应用 → 创建应用」，应用类型选择 Business（商务）。
  3. 创建后在「应用设置 → 基本信息」能看到：
    • 应用编号 App ID → 对应系统 appId
    • 应用密钥 App Secret → 对应系统 appSecret

三、第 2 步：添加 Facebook Login for Business

Meta 开发者平台 ↗打开后选择自己的应用，再按下方步骤操作。
  1. 在应用里点「添加产品」，选择 Facebook Login（登录）。
  2. 勾选 Facebook Login for Business 的「配置」。

四、第 3 步：申请页面发布权限

Meta 开发者平台 ↗打开后选择自己的应用，再按下方步骤操作。

在「应用审核 → 权限和功能」中申请（Development Mode 下默认可直接使用）：

  • pages_show_list —— 读取你的 Page 列表
  • pages_read_engagement —— 读取 Page 互动数据
  • pages_manage_posts —— 发布到 Page（核心）

五、第 4 步：配置回调地址

Meta 开发者平台 ↗打开后选择自己的应用，再按下方步骤操作。

在「Facebook Login → 设置」中，把下面地址加到 有效的 OAuth 跳转 URI：

http://localhost:5001/platform/facebook/oauth/callback

六、第 5 步：准备 Facebook Page

打开 Facebook ↗
  1. 确保你的 Facebook 账号名下有一个 Page（公共主页），没有就先创建一个。
  2. 你必须是该 Page 的 管理员，否则授权时拿不到该 Page。

七、第 6 步：填进系统「平台配置」页

打开平台配置 / 账号授权 ↗
  1. 打开系统「平台配置」页：本地平台配置页面 ↗（登录 admin@qq.com / admin123）。
  2. 找到「Facebook」行，点「配置」，填：
    • 应用ID ← App ID
    • 应用密钥 client_secret ← App Secret
  3. 点「保存」。

八、第 7 步：点「授权」拿到 Page Token

打开平台配置 / 账号授权 ↗
  1. Facebook 行点「授权」，跳转 Meta 登录授权页。
  2. 选择你的 Page，同意授权。
  3. 授权成功自动跳回，Page Token 已自动回填。

九、成功标志

打开平台配置 / 账号授权 ↗ 打开视频发布 ↗
  • 页面弹出「Facebook 授权成功，令牌已保存」
  • 表格里 Facebook 行变成「已配置凭证」
  • 数据库里写入了 60 天长期 token + pageId + pageAccessToken

十、易错点汇总

Meta 开发者平台 ↗ 打开平台配置 / 账号授权 ↗
坑现象 / 原因解决办法
报 #100 无权限用了用户 token 而不是 Page token确认授权时选了 Page，且拿到的是 Page Token
授权看不到 Page你不是 Page 管理员先把账号设为 Page 管理员
别人用不了Development Mode 只有 App 成员能授权对方自建 App，或你把他加为「测试用户」
token 过期Meta token 约 60 天失效无刷新机制，过期后重新「授权」
